# Clean up

## stop sandbox

```text title= showLineNumbers
sbx stop <sandbox-name>
```

## remove sandbox

```text title= showLineNumbers
sbx rm <sandbox-name>
```

<Admonition type="caution" title="caution">

Removing sandbox delete everything inside it (installed packages, docker images). Files on host mapped into sandbox are unaffected.

</Admonition>
